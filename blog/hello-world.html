Hello, World — New Website

March 11, 2026 · 2 min read

The old site ran on Hugo with the Academic CV theme — a perfectly good setup, but one that accumulated config files, shortcodes, and theme overrides I no longer fully understood. This is the replacement: a single index.html file, a handful of blog posts, and a Python script that keeps the publications in sync with a .bib file.

What changed

The new stack is deliberately minimal: plain HTML, CSS custom properties for the design tokens, and a small amount of vanilla JavaScript for the mobile menu, the publication filter, and scroll animations. No build step, no node_modules, no framework. You can open index.html directly in a browser and it just works.

Fonts are loaded from Google Fonts as a progressive enhancement — the page renders instantly with system fonts, then switches to DM Serif Display and Inter once they arrive.

Adding new content

Papers — add an entry to publications.bib and run: 

pip install bibtexparser
python scripts/bib_to_html.py

The script rewrites the publications section of index.html in place.

Blog posts — copy blog/_template.html to a new file, fill in the title, date, tags and prose, then add a card to the blog section of index.html.
